# Workflows

Record of what was actually run in each test, transcribed from my workflow notes (one Google Docs document per test).

```
workflows/<test>/
  commands.sh   commands in the order they were run, with the original file names and paths
  notes.md      summary, result recorded for each ecoPrimers run and notes on inconsistencies
```

## `workflows/` vs `scripts/`

- **`workflows/`** is the history. The commands keep the names used at the time (`banco_<test>`, `sequencias_fase1.gb`, `16s_iguacu_definitivo.fasta`, the local conda path) and include runs that were later replaced. These files are a record and are not meant to be run.
- **`scripts/`** is the reproducible version. The same steps run with standardized paths and with the parameters in `config/targets.tsv`.

The ecoPrimers parameters in both are the same: for the final runs of the seven tests that have a FASTA file in the repository, the `-r`, `-i`, `-l`, `-L`, `-3`, `-O` and `-U` values generated by `scripts/04_run_ecoprimers.sh` match the ones in `commands.sh` (`12s_bryconidae` could not be checked because its FASTA file is missing).

The GenBank queries are not repeated here; each `notes.md` links to its file in `config/queries/`.
